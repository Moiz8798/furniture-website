# 🪑 Ajmal Furniture Website

A modern furniture website built using PHP, HTML, CSS, and JavaScript. This project showcases a collection of stylish and affordable furniture with a clean and responsive user interface.

---

## 📌 Features

* 🛋️ Browse furniture products
* 🔍 Search and filter functionality
* 🛒 Add to cart system
* 📱 Responsive design (mobile-friendly)
* 🔐 Basic backend using PHP

---

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL

---

## 📂 Project Structure

```
assets/      → CSS, JS, images  
includes/    → Header, footer, DB connection  
pages/       → Website pages  
admin/       → Admin panel  
database/    → SQL file  
```

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/ajmal-furniture-website.git
```

### 2. Move project to server directory

* XAMPP → `htdocs`
* WAMP → `www`

### 3. Import database

* Open phpMyAdmin
* Create a database
* Import `database/ajmal_furniture.sql`

### 4. Run the project

Open in browser:

```
http://localhost/ajmal-furniture-website
```
