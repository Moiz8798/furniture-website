## ⚙️ Getting Started

### Prerequisites
- [XAMPP](https://www.apachefriends.org/) or [WAMP](https://www.wampserver.com/) installed
- A web browser

---

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/ajmal-furniture-website.git
```

---

### 2️⃣ Move to Server Directory

```bash
# XAMPP users
Move folder to → C:/xampp/htdocs/

# WAMP users
Move folder to → C:/wamp/www/
```

---

### 3️⃣ Import the Database

1. Open your browser and go to `http://localhost/phpmyadmin`
2. Click **New** → create a database named `ajmal_furniture`
3. Click **Import** → select `database/ajmal_furniture.sql`
4. Click **Go**

---

### 4️⃣ Configure Database Connection

Open `includes/db.php` and update if needed:

```php
$host     = "localhost";
$username = "root";
$password = "";           // your MySQL password
$database = "ajmal_furniture";
```

---

### 5️⃣ Run the Project

Open your browser and visit:
```
http://localhost/ajmal-furniture-website
```

**Admin Panel:**
```
http://localhost/ajmal-furniture-website/admin
```
